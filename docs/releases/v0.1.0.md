# NetControl 0.1.0 (Rust rebuild)

First packaged release of the Rust reimplementation of
[NetControl](https://github.com/nov0caina/NetControl) by Abel Meza Enriquez
(MIT).

## Downloads (Windows x64)

| File | Description |
| --- | --- |
| `NetControl-0.1.0-windows-x64-portable.zip` | Portable; extract and run `NetControl.exe` |
| `NetControl-0.1.0-windows-x64-user-setup.exe` | Per-user installer: Start Menu shortcuts, uninstaller |
| `SHA256SUMS.txt` | SHA-256 checksums |

Live capture needs [Npcap](https://npcap.com/). Demonstration mode needs
nothing. No Rust or .NET installation is required. Binaries are unsigned.

## Highlights

- Demonstration mode with simulated devices, and Live mode with **passive**
  ARP/IPv4 observation (no scans or probes are sent).
- Readable interface names (`Ethernet 2 — 192.168.1.119`) mapped to Npcap
  devices by adapter GUID.
- Live diagnostics panel: capture runtime, privileges, capture device, last
  error, and the reason no devices are shown.
- Settings persist per user or beside the executable (portable).

## Important limitations

- ARP redirection/spoofing, interception, and blocking are **not implemented**.
- Bandwidth limits are **dry-run**: planned commands are shown, never applied.
- Linux and macOS are **not tested** and have no binaries in this release.

See `CHANGELOG.md` for the full list of changes and `docs/INSTALL.md` for
installation and troubleshooting.
